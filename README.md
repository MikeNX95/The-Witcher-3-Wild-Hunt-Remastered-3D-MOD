# The-Witcher-3-Wild-Hunt-Remastered-3D-MOD



## 📦 Installation
1. Download and extract `wit3D.zip`.
2. Place `dxgi.dll` / `3D-6DOF config.ini` and `3D-6DOF resolution.ini` into your main game directory right next to `game.exe`.
3. Launch the game and enjoy!

### LeiaSR Display Users
1. Copy `leiasr_shim.dll` into the game directory next to `game.exe`.
2. Set your **Stereo Output** to `7`.
3. Launch the game and enjoy!
